Formatting guide

When Basic formatting is on, you can use:

  • # Heading, ## Subheading, ### Small heading
  • **bold**, *italic*, ***bold italic***
  • - item or • item for bullet lists, 1. item for numbered lists (indent with 2 spaces to nest)
  • > quote for a block quote, --- for a divider
  • A line with only [pagebreak] starts a new page
  • Use \* to type a literal asterisk

Line breaks are kept exactly as you type them; long lines wrap automatically.
